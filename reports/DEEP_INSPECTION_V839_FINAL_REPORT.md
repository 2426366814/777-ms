## 二、问题修复记录

### 已修复问题 #1: 知识库保存失败

**问题描述**: 在知识库页面填写表单后点击保存，显示"操作失败"

**根本原因**: 前端代码 `knowledge.html` 第689行缺少 `await` 关键字

**修复方案**: 
```javascript
// 修复前
res = api('/', { method: 'POST', body: JSON.stringify(data) });

// 修复后
res = await api('/', { method: 'POST', body: JSON.stringify(data) });
```

**修复文件**: `web/knowledge.html`

**验证结果**: ✅ 知识添加成功，知识条目从9变为10
