API 基础地址

https://memory.91wz.org/api/v1

API 认证方式 - 系统支持两种认证格式，任选其一即可：

方式 1：x-api-key（推荐）

x-api-key: 777_xxx

语义清晰，符合行业标准

方式 2：Authorization: Bearer

Authorization: Bearer 777_xxx

兼容性好，通用性强

登录后在控制台获取您的 API Key。两种方式功能完全相同。

聊天接口 (OpenAI 兼容)

POST /chat/completions

OpenAI 兼容的聊天补全接口，支持所有 OpenAI SDK

# cURL 示例 curl https://memory.91wz.org/api/v1/chat/completions \ -H "Content-Type: application/json" \ -H "Authorization: Bearer YOUR_API_KEY" \ -d '{"model": "gpt-4", "messages": [{"role": "user", "content": "Hello!"}]}'
GET /models

获取可用模型列表

记忆管理接口

GET /memories

获取记忆列表，支持分页和筛选

POST /memories

创建新记忆

{ "content": "记忆内容", "tags": ["标签1", "标签2"], "importance": 5 }
GET /memories/:id

获取单个记忆详情

PUT /memories/:id

更新记忆内容

DELETE /memories/:id

删除记忆

智能搜索接口
