常见问题

什么是记忆存储？
记忆存储是指系统为您保存的记忆条目数量。每条记忆包含内容、标签、重要性等信息，AI 在对话时会自动检索相关记忆。
支持哪些 LLM 提供商？
我们支持 OpenAI、Claude、Gemini、DeepSeek、通义千问、文心一言等 23+ 主流 LLM 提供商，您可以在设置中自由切换。
如何获取 API Key？
注册账号后，在控制台的「安全设置」页面可以创建和管理 API Key。专业版及以上用户享有完整的 API 访问权限。
数据安全如何保障？
我们采用多用户数据隔离架构，每个用户的数据完全独立。支持端到端加密和自动备份，确保您的数据安全。
