隐私政策

最后更新：2025年3月14日

1. 信息收集

777-MS 记忆系统收集以下信息：

  • 账户信息：用户名、邮箱地址、密码（加密存储）
  • 记忆数据：用户创建的记忆内容、标签、分类
  • 知识库文件：用户上传的文档和知识库内容
  • 使用日志：API调用记录、登录日志（用于安全审计）

2. 数据隔离

我们采用多用户数据隔离架构，确保：

  • 每个用户的数据完全独立存储
  • 用户无法访问其他用户的数据
  • API Key 与用户账户绑定，确保数据访问安全

3. 数据使用

您的数据仅用于：

  • 提供记忆管理和智能复习服务
  • LLM 对话上下文载入
  • 知识库语义搜索
  • 系统功能改进（匿名化数据）

4. 数据安全

我们采取以下安全措施：

  • HTTPS 加密传输
  • 密码加密存储
  • API Key 安全管理
  • 定期数据备份
  • 访问日志审计

5. 数据保留与删除

您可以随时：

  • 导出您的所有数据
  • 删除单个记忆或知识库文件
  • 注销账户并删除所有关联数据

6. 第三方服务

我们使用以下第三方服务：

  • LLM 提供商：OpenAI、Claude、Gemini 等（用于 AI 对话）
  • 云服务：服务器托管和数据库服务

第三方服务提供商均有严格的隐私保护政策。
